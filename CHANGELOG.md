# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project
follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Before
v1.0.0, any minor release may contain breaking changes.

## [Unreleased]

## [1.2.0] - 2026-11-02

### Added

- Public repository scaffolding: CI (vet, race tests, golangci-lint,
  govulncheck, CodeQL, OpenSSF Scorecard), Dependabot, tag-based releases,
  CONTRIBUTING (DCO), SECURITY, CODE_OF_CONDUCT, issue templates and a pull
  request template.

### Changed

- README rewritten with a worked example, a package table linking tests, and
  a section on crypto and FIPS scope.
- Internal planning identifiers and product names were removed from comments.
- Documentation states which parts are seams or unfinished (see the README
  section "Status and limitations").

## [1.1.0] - 2026-09-17

### Added

- First public release under Apache-2.0, with the packages `chain`,
  `cryptoprofile`, `govdecision`, `identity`, `resilient` and `spool`.
